A desktop-oriented launcher for Android/EnergyOS.
## Latest release
The latest release is Version 2, which includes some fixes to the customisation app, bug squashing overall and adds background opacity to the app drawer. Other than that not much has been changed, but we are currently working on adding proper windowing with hot corners for snapping together.
## Installation
First, download the apk and install. Then, open the app, and give the app the required permissions. If certain permissions are locked, open (Android 13+) Settings and go to "Apps", then KineticLauncher, press the three dots and select "Allow restricted settings". Otherwise use the help section on the smartdock project which provides an adb command for devices running Android 12 and below.
## Requirements
You need a device running Android 10 and up, and no root is required, but to access full features make it a system app, or you have to root it.
